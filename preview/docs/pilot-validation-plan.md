# Pilot validation plan

## 무엇을 확인할 것인가

목표는 짧아 보이는 검사가 아니라, 응답자가 이해하기 쉽고 각 주체에게 실제 도움이 되는 검사입니다. 아래 인원·회차는 시작을 위한 운영 제안이며 통계적으로 충분한 표본 크기를 뜻하지 않습니다. 정식 신뢰도·타당도·집단별 비교의 표본 설계는 측정 전문가와 별도로 정합니다.

## 1단계: 문항 인지면담

시작 제안: 구직자 8~12명. 아동교육 경험자, 미경험 작가, 전환 준비자, 성인 교육·문화·디지털 분야 경험자가 포함되도록 합니다. 검사 결과를 채용 결정에 사용하지 않는 자발적 파일럿으로 안내합니다.

진행자는 답변을 유도하지 않고 다음을 묻습니다.

1. 이 질문을 본인 말로 다시 설명해주세요.
2. 누구의 행동을 떠올렸나요? 본인, 관리자, 학습자 중 누구였나요?
3. 두 선택지가 동시에 좋거나 둘 다 싫을 수도 있나요?
4. 경험이 없을 때 어떤 항목을 골라야 한다고 이해했나요?
5. 실제와 다르게 ‘좋아 보이는 답’을 골라야 할 것 같았나요?
6. 이 질문에 답하면 결과지에서 무엇을 알려줄 것으로 기대하나요?

기록: 문항 ID·판본 / 이해한 의미 / 답하기 어려운 이유 / 수정 제안 / 답변 시간 / 피로가 느껴진 구간. 민감한 개인 정보와 제3자 식별 정보는 별도로 수집하지 않습니다.

## 2단계: 현직자 내용 검토

각 분야별로 역할이 다른 현직자 최소 2명의 독립적인 검토로 시작합니다. 이는 내용 검토의 시작점이며 완료 판정이나 타당도 인증이 아닙니다. 성인 교육을 포함한 아홉 분기 모두 검토가 필요합니다.

각 D3·S3에 대해 실제로 발생하는 상황인지, 선택지의 첫 행동과 이후 행동이 섞이는지, 운영·안전 제약이 일관적인지, 권리 침해를 유연성으로 잘못 읽을 위험이 있는지 확인합니다.

채용처 HJ·HE는 지원자 J3·E3와 행동 주체·시간 범위·내용이 같은지 확인합니다. 아동 안전 및 현장 위험은 전문 검토와 기관의 실제 절차를 확인하고 일반 성향과 섞지 않습니다.

## 3단계: 구판과 개정판 비교

동의한 참여자를 대상으로 시행 순서를 교차 배정하고, 두 검사를 연이어 답하면서 생기는 피로·기억 효과를 기록합니다. 반복 측정 간격은 경험 변화 가능성과 문항 기억 효과를 고려하여 설계합니다. 고정 인원이나 일정만으로 동등성 검증이 끝났다고 말하지 않습니다.

비교 항목:

- v3.0→v3.1에서 영역별 5→4문항으로 바꾼 흥미 6개와, 구성 그대로인 나머지 24개 요약 항목의 차이와 원인
- 삭제 전의 같은 원응답으로 5문항 평균과 남은 4문항 평균을 비교: 3.5 경계 통과 여부, 탐색 분야 변화, 세부 활동 선호 손실. 이것만으로 실제 응답 부담·순서 효과가 검증되지는 않음
- 단축판에서 한 개의 판단 어려움·결측으로 해당 평균이 보류되는 빈도, 경험이 적은 사람에게 필요한 확인 경로
- 핵심 업무 선호, 필수 조건, 비선호·협의 가능 범위가 빠지지 않는가
- 제안 방향이 달라졌다면 질문 의미 수정·근거 보완·조건 추가 중 무엇 때문인가
- 에듀핀 담당자가 같은 상담 질문을 더 짧은 시간 안에 찾을 수 있는가
- 구판의 불필요한 확신이 줄었는가
- 총 응답시간, 모듈별 시간, 복합 문항의 세부 입력 수, 중단·재개·결측

이번 판에서 묻지 않는 성격·진로 자기결정 7개 항목에는 동등성 주장을 하지 않습니다. 그 정보가 실제로 필요하다는 근거가 생기면 허가와 측정 설계를 검토한 별도 선택 모듈로 다룹니다.
v3.1의 4문항 흥미 척도 역시 구판과 측정 동등성이 확인된 단축형이 아닙니다. 잠정 기준과 제외 문항을 검토 대상으로 남깁니다.

## 4단계: 세 결과지의 유용성 평가

### 지원자

- 내 모습과 맞는 부분 / 다른 부분 / 지나치게 단정적으로 느껴진 부분
- 결과를 보고 처음 알게 된 나의 선택 기준 한 가지
- 채용 공고에서 확인하고 싶은 질문을 스스로 말할 수 있는가
- 검사에 쓴 시간 대비 얻은 가치와 반복·장황한 설명

### 채용처

- 이력서만 보았을 때와 달리 알게 된 직무 관련 정보
- 서술이 선호를 능력·성과로 오해하게 하는가
- 핵심 차이와 미확인 조건을 첫 화면에서 찾는가
- 경험이 없는 지원자에게도 공정하게 물을 수 있는가
- 최초 1개월 운영 합의에 실제로 쓸 수 있는가

### 에듀핀

- 1분 안에 필수 조건, 명시적 비선호, 새 분야 의향, 다음 질문을 찾는가
- 자리 제안의 근거를 최소 두 개의 실제 응답이나 확인된 조건으로 설명하는가
- 가상 상황과 직접 경험을 섞지 않는가
- 담당자 두 명이 같은 자유서술을 보고 비슷한 확인 질문을 만드는가
- 신규 분야 연결에서 교육·적응 지원과 거절 가능성을 설명하는가

## 5단계: 공정성·품질·변화 검토

직무 관련 응답은 같게 두고 이름·성별·연령 암시·학교명·문체만 바꾼 가상 입력으로 해석 차이를 확인합니다. 사람의 검토 과정도 편향될 수 있으므로 익명화된 사례와 공통 확인 기준을 사용합니다. 정식 집단별 분석이 필요하면 별도의 동의·표본·보관 계획을 먼저 세웁니다.

‘경험 없음’을 인격·공감·책임감 부족으로 해석하지 않는지 확인합니다. 상황 태그는 이유의 일부이고 서술 길이는 사고 깊이 점수가 아님을 명시합니다.

결과의 변화는 모듈별 원응답·문항판·검사 시점과 함께 보관합니다. 5개 체크인만 했다고 검사 전체의 시점을 새로 갱신하지 않습니다. 연락 시에는 구직 의향·일정·보수·새 분야 의향 등 현재 조건을 우선 재확인합니다.

## 수용·수정 판단

다음 문제가 발견되면 공개 사용 전에 수정합니다.

- 질문을 반복해서 다른 주체나 의미로 이해함
- 근거 없는 성격·능력·적합성 문장 생성
- 핵심 미확인 조건이나 지원자의 명시적 제약이 누락됨
- 같은 답이 문체·개인정보 암시에 따라 다르게 평가됨
- 안전·권리 문제를 단순한 선호 차이로 처리함
- 응답 부담이 늘었는데 새 정보가 실제 선택·상담에 사용되지 않음

## 참고 기준

O*NET의 공식 매뉴얼은 문항 개발·신뢰도·타당도·직업 연결을 별개의 검토 영역으로 다룹니다. 이 구조를 참고하되 에듀핀의 수정 문항이 O*NET과 동등하게 검증됐다는 뜻으로 쓰지 않습니다. [O*NET Interest Profiler Manual](https://www.onetcenter.org/reports/IP_Manual.html)

직무 관련 평가에는 직무 분석과 적절한 타당도·공정성 검토가 필요하다는 전문 기준을 참고합니다. 한국 서비스에 적용되는 법적 판단을 대신하지 않습니다. [SIOP 공식 권고](https://www.siop.org/wp-content/uploads/2025/12/UniformSelectionStatement_121525.pdf)

BFI-2의 비상업적 연구 이용과 상업적 이용 조건은 다릅니다. 이번 판에서 빠진 B3를 재도입하려면 권리자의 허가 범위와 번역·활용 조건을 먼저 확인해야 합니다. [Berkeley Personality Lab](https://www.ocf.berkeley.edu/~johnlab/bfi.html)
