## 해설에서 특히 확인한 부분

- 첫 설명은 실제 답변 근거가 있을 때만 생성. 빈 답변은 이야기를 더 듣고 싶다는 안내로 표시
- 분야 추천을 보류하더라도 근거 있는 자기이해는 유지
- 첫머리에서 설명한 카드를 본문 첫 장에서 반복하지 않음
- 지원자와 채용처의 문장 수신 대상을 구분
- 채용처에 개인 사정·자유서술 원문·다른 자리 비교를 노출하지 않음
- 필수 조건 차이와 경험자 요건을 첫 설명에서 확인. 가까운 핵심 조건이 없으면 있다고 쓰지 않음
- 에듀핀의 37개 항목과 모든 원응답을 계속 열람 가능
- 입력한 HTML은 실행하지 않고 글로 표시. 검토용 채용처 탭은 외부 발송이 아님
- 채용처 첫 화면에서 중요 조건 부합 개수·강점·확인할 점을 같은 순서로 표시
- 중요 조건별 설명은 채용처 답·지원자 답·판단 근거를 함께 보이며, 단일 결과에서 ‘가장’ 순위를 만들지 않음
- 채용처에는 ‘궁금하다면, 어떤 답에서 나왔는지 보기’와 문항 ID를 표시하지 않고, 에듀핀 해설에만 유지
- 지원자의 특성은 요약에서 한 번만 설명하고, 동일한 행동 설명을 다음 장에서 반복하지 않음
- 채용처용 문장의 ‘이 자리’를 ‘모집 직무’ 또는 ‘현재 모집 직무’로 구체화

## 화면 검증의 범위와 제한

DOM 검사에서 K3-07 삭제, 후속 17번 및 흥미 문항의 연속 번호, 03·04·05번 입력 변경의 해설 반영, 채용처 문구 유지도 확인했습니다. DOM 검사로 제목·첫 문단·섹션 순서·펼쳐보기·번호·분모·탭·분기·결과 생성과 채용처 요약판의 상태·조건 카드 개수를 확인했습니다. 6영역 프로필의 여섯 표시값·완결 면·미응답 상태와 지원자·에듀핀·채용처별 표시 여부를 확인했습니다. 또한 채용처 화면에 근거 펼쳐보기·문항 ID·‘이 자리’ 표현이 남지 않고, 지원자 특성 설명이 한 번만 나오는지 확인했습니다. CSS는 결과지 전용 선택자를 중심으로 제한해 질문지 입력 레이아웃이 바뀌지 않도록 했습니다.

실제 브라우저 화면의 픽셀·모바일·인쇄 검증은 완료하지 못했습니다. computer-use 스킬의 Orca 실행이 runtime_open_timeout으로 끝났고, 대체 브라우저 경로에서도 로컬 파일 URL 열기가 브라우저 보안 정책에 의해 차단됐습니다. 우회하지 않고 파일 기반 DOM 검사와 소스 검토만 진행했습니다. 이 제한을 시각 검증 통과로 기록하지 않습니다.
