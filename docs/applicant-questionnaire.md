## 지금 찾는 일의 조건

현재의 선택 기준을 기록해요. 미정인 조건을 불리하게 해석하지 않고, 실제 자리를 살펴볼 때 다시 확인합니다.

### K3-01. 보수는 어떤 기준으로 살펴볼까요?

- 보수 기준: 시급 / 월급 / 회당 / 프로젝트당 / 아직 정하지 못했어요
- 이보다 낮으면 선택하기 어려운 금액 (원): 숫자 0~100000000, 미정이면 빈칸
- 희망 금액 (원): 숫자 0~100000000, 미정이면 빈칸

문항판 3.0

### K3-02. 일할 수 있는 요일과 시간을 알려주세요.

- 가능한 요일: 월 / 화 / 수 / 목 / 금 / 토 / 일 / 아직 정하지 못했어요
- 가능한 시간대: 오전 / 오후 / 저녁 / 아직 정하지 못했어요
- 일주일에 가능한 최대 시간: 숫자 0~168, 미정이면 빈칸
- 시작 가능한 날짜: 날짜, 미정이면 빈칸
- 고정 일정이나 추가로 설명할 점 (선택): 짧은 글

문항판 3.0

### K3-03. 어떤 계약 형태를 살펴보고 싶으세요?
