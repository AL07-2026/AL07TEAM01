## v3.2: 질문과 분석은 유지하고 해설의 말투·순서 개정

2026-09-06. v2.0의 설명 흐름을 참고해 중요한 이야기를 먼저 풀어주고, 그 뒤에 일의 모습·선택 기준·다음 대화가 이어지도록 바꿨습니다. v2.0의 고정 예시 점수·경력·추천을 옮긴 것은 아닙니다. v3.1의 동일한 실제 응답 데이터와 조건부 해석에서만 문장을 만듭니다.

- 지원자: 두 문단의 첫 이야기 → 핵심 기준 → 함께 보인 모습 → 편한 일과 환경 → 조건·경험 → 살펴볼 방향 → 질문 → 작은 다음 행동. 첫 설명에 사용한 카드는 본문에서 그대로 반복하지 않습니다.
- 에듀핀: 지원자의 모습과 중요 기준 → 선호·비선호·현재 조건 → 자리별 대화와 먼저 확인할 점 → 판단 방식·직접 설명 → 공유 검토 → 촘촘한 전체 37항목과 원응답.
- 채용처: 핵심 차이·필수 조건·경험 요건부터 → 첫 질문 → 가까운 업무 방식 → 꼭 이야기할 차이 → 면접 → 초기 운영 합의 → 해석의 범위.
- 근거 문항 ID·계산표·기술 설명은 펼쳐보기로 옮겼습니다. 답변 부족, 경험자 요건 미확인, 필수 조건 차이, 아동 안전 확인을 긍정적인 문장 뒤에 숨기지 않습니다.
- 짧은 제목, 문단 사이 여백, 비교용 간단한 줄 요약, 보고서에만 적용되는 글자 크기·행간을 정리했습니다. 질문 화면의 문구와 입력 구조는 바꾸지 않았습니다.
- 원응답·점수·추천 방향·매칭 결과·공유 판단은 그대로 두고, `reading`에 해설 표현을 추가했습니다. 입력·분석 판본은 3.1을 유지하므로 문장 개정 때문에 재응답을 요구하지 않습니다.
- 자유서술을 새로 의미 분석하거나, 근거에 없던 강점·능력·분야 선호를 추가하지 않았습니다. 채용처 해설은 기존의 개인정보 제외 범위를 그대로 따릅니다.

검증은 `verification-results.md`, 문체 원칙과 읽기 순서는 `report-reading-guide.md`를 참고하세요. 아래는 보존한 이전 구현 이력입니다.

## v3.0 구현 이력

## 목적과 상태

지원자에게는 자기이해와 일자리 선택 기준을, 채용처에는 서류에서 드러나기 어려운 업무 선호와 확인 질문을, 에듀핀에는 실제 연결 판단과 상담을 돕는 근거를 제공합니다.

v2.0을 보존하고 별도 폴더에 작성했습니다. 새 버전은 현장 검증 전 개정 초안입니다. 문항과 해석 규칙이 바뀌었으므로 v2.0 결과와 같은 검사라고 표기하지 않습니다.

## 1. 근거 없는 해석 차단 — 구현

- 빈 답변에서 특정 분야 추천이나 활용 가능 판정을 만들지 않습니다.
- 1~5·1~7 정수 범위, 선택지, 최대 선택 수, 날짜, 금액 순서, 업무 비중 합계를 검증합니다. null·빈칸·미정은 0으로 읽지 않습니다.
- 두 문항 묶음은 두 답이 모두 있을 때만, 다섯 문항 묶음은 네 답 이상일 때만 요약합니다. 이는 보수적인 운영 규칙이며 타당도 연구로 정한 절단점은 아닙니다.
- 가운데 이유를 두 방식 수용 / 상황에 따라 다름 / 두 방식 모두 비선호 / 경험 부족으로 구분합니다. 수용 여부를 확인하지 않은 가운데는 자동 일치로 계산하지 않습니다.
- 현재 선택 분야에서 유효한 숫자 답변에 붙은 A/B/C만 집계합니다. 다른 분야의 과거 입력이 근거 개수를 부풀리지 않습니다.
- 자기이해 해석과 분야 추천의 준비 상태를 분리했습니다. 환경 선호가 불분명해도 충분한 최근 행동 답변에서 얻은 자기이해까지 지우지 않습니다.
- 일치해도 핵심 조건은 실제 경험을 확인합니다. 미확인 핵심 조건이 사라지지 않습니다.
- 채용처 초안은 내부에 남기고, 실제 공유용 데이터는 동의·완결성·현재 답변에 연결된 담당자 승인 등을 확인한 경우에만 반환합니다. 외부 발송은 구현하지 않았습니다.

## 2. 실제 매칭 조건 보강 — 구현

지원자: 최소·희망 보수, 가능한 요일·시간·주당 시간·시작일, 계약 형태, 통근 시간, 이동 지원 필요, 개인 활동 시간, 새 분야 제안 범위, 망설임, 분야별 실제 경험, 필수 조건·명시적 비선호·협의할 부분.

채용처: 제안 보수 범위와 준비시간 처리, 실제 일정, 계약과 이동 지원, 업무 비중, 미경험자 검토 여부, 초기 지원, 현장의 어려움, 조정할 수 있는 운영 범위.

같은 단위의 보수만 비교합니다. 보수 범위가 최소 조건에 걸쳐 있으면 협의 필요로 표시합니다. 같은 시·도라도 통근 가능으로 단정하지 않습니다. 개인 활동의 자유서술은 자동 일정 판정이나 채용처 원문 전달에 쓰지 않습니다.

초보자 수용 여부와 경험 부족은 나누어 표시합니다. 관련 분야를 선택하지 않았다는 사실만으로 미경험이라고 판단하지 않습니다. 성향 일치로 채용처의 경험 요건을 대신하지 않습니다.

## 3. 상황 답변·우선순위 연결 — 구현과 한계

- 최근 행동, 환경 선호, 일의 의미, 반복된 상황 이유를 연결하는 교차 해석을 구현했습니다.
- 모든 교차 해석은 관찰 / 문항 근거 / 미확인 / 후속 질문을 함께 가집니다.
- 같은 행동이라도 선택 이유와 직접 쓴 설명을 별도로 표시합니다. 자유서술은 있는 그대로 인용하고, 숨은 동기·정신상태를 추정하지 않습니다.
- 이유 태그 변경은 교차 해석과 확인 질문에 반영됩니다. 상황 질문을 직무 적합 점수에 더하지는 않습니다.
- 지원자의 우선순위와 궁금한 정보는 상담 첫 화면과 자리별 대화 자료에 연결합니다. 근거 없이 가중치를 붙여 단일 순위를 만들지 않습니다.
- 자유서술을 자동으로 깊이 해석하는 언어모델 기능은 넣지 않았습니다. 원문과 근거를 보며 담당자가 확인하도록 했습니다. 향후 추가한다면 동일 사례의 문체·개인정보 암시만 바꾼 비교, 근거 추적, 사람의 수정·삭제 경로를 먼저 검증해야 합니다.

## 4. 문항과 결과 구성 정리 — 구현

기존 질문 22개를 필수 질문지에서 제외했습니다.

- B3 16개: 사교성·주도성·활력·신뢰 성향. 상업 이용 허가·번역·측정 범위와 실무 활용을 별도 재검토합니다. 이번 판에는 다시 묻거나 다른 답으로 추정하지 않습니다.
- X3-U03·U04 및 X3-D01~D04 6개: 자기평가 대신 실제 우선순위·조건·제안 의향·확인 질문을 통해 실무에 연결합니다. 기존 ‘진로 자기결정’ 척도를 동일하게 유지했다고 주장하지 않습니다.

조건·경험 10묶음과 아동 접촉 여부 1개를 추가했습니다. 기본 134개 묶음, 아동 접촉 시 138개입니다. 선택 서술 2개를 포함한 최대 표시 수입니다. 각 묶음 안의 세부 입력, 경험 근거·이유 선택, 가운데 후속 질문은 이 숫자와 별개입니다. 따라서 실제 응답 시간이 줄었는지는 측정해야 합니다.

37개 기존 요약 항목의 연결은 보존하지만 실제 계산은 30개만 합니다. 제외된 7개를 ‘미측정’으로 표시합니다. 같은 완전 응답의 유지 척도 평균과 구판 계산이 일치하는지 확인하되, 이것은 측정 동등성의 증거가 아닙니다.

성인 미술교육·워크숍 분기를 추가했습니다. E3-03·07·11, J3-05는 행동 주체나 양쪽 의미를 명확히 했고 채용처 쪽 문구와 일치시켰습니다. 의미가 달라진 문항은 문항판 3.0 및 재응답 필요로 표시합니다.

지원자 결과는 여섯 본문 구간과 상세 근거, 채용처 결과는 핵심 판단·업무 방식·차이·면접·초기 합의·한계로 구성했습니다. 에듀핀은 실제 조건과 자리별 대화를 먼저 보고, 37개 연결표·원응답은 뒤에서 펼치도록 했습니다.

과도하게 긴 실습이나 시간을 확인하지 않는 실제 수업 실험은 없앴습니다. 모의 설명·참관·짧은 개인 작업처럼 부담과 위험이 작은 활동으로 바꿨습니다.
